Plugin

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

The plugin itself: what a plugin implements, and what it is given.

A plugin's own lifecycle, settings, folder and log.

Description

A Rust plugin implements the Plugin trait; a Java plugin extends VoxelmonPlugin. The server calls enable once loaded, world_ready once players may join and disable when stopping or reloading. See Writing a plugin for the manifest.

Methods

ReturnsMethodDescription
nothingenable(server: Server)Called once loaded: register events, commands and tasks here.
nothingworld_ready()Called once the world has loaded and players may join.
nothingdisable()Called when the server stops or the plugin is reloaded: save what it keeps.
Stringid()Its id from the manifest.
Stringversion()Its version from the manifest.
Configconfig()Its config.toml, written from its defaults the first time.
nothingreload_config()Reads config.toml again.
nothinglog_info(text: String)A line in the console, marked with the plugin's name.
nothinglog_warn(text: String)A warning in the console.
nothinglog_error(text: String)An error in the console.
