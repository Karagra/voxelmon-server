Server

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

Given to the plugin in enable(); one per server.

The running server: its players, world, settings and console.

Description

Everything a plugin does starts here. The server ticks 60 times a second; plugin code runs on the tick, so a plugin never needs to lock anything to read the world.

Properties

TypeNameDescription
StringtitleThe title players see when they look up the join code.
StringdescriptionThe line under the title.
Stringjoin_codeThe six-character join code.
intmax_playersPlayers allowed at once.
StringversionThe server's version; players must run the same game version.
inttickTicks since the server started (60 a second).
WorldOptionsoptionsDifficulty, combat style, keep inventory, creative.
