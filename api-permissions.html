Permissions

Available. Every call here works on servers today.

Reached from the server: server.permissions().

Who may do what: operators and permission names.

MethodDescription
fn has(&self, player: Player, permission: &str) -> Result<bool>boolean has(Player player, String permission)Whether a player has a permission.
fn declare(&self, permission: &str, default: PermissionDefault, description: &str) -> Result<()>void declare(String permission, PermissionDefault default_, String description)Names a permission this plugin checks, so owners and managers can list it.
fn declared(&self) -> Result<Vec<String>>List<String> declared()Every permission every plugin declared.
fn is_operator(&self, id: PlayerId) -> Result<bool>boolean isOperator(String id)Whether a player is an operator.
fn add_operator(&self, id: PlayerId) -> Result<()>void addOperator(String id)Makes a player an operator (written to server.toml).
fn remove_operator(&self, id: PlayerId) -> Result<()>void removeOperator(String id)Takes a player off the operators.

Description

A permission is a name such as warps.set. Operators, listed in server.toml (operators, by player ID), have every permission. Anything finer (groups, ranks) comes from a permission manager plugin offering the permissions service; has then asks it.

PermissionDefault

One of a fixed set of values.

Who has a permission when no manager says otherwise.

ValueMeaning
PermissionDefault::EveryonePermissionDefault.EVERYONEEveryone.
PermissionDefault::OperatorsPermissionDefault.OPERATORSOperators only.
PermissionDefault::NobodyPermissionDefault.NOBODYNobody.
