Types

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

Values used throughout the API.

The small values every page uses: places, blocks' positions, IDs, colours, times and the like.

Place

A point in the world, in blocks: x, y (up) and z, each a float. One block is one metre.

BlockPos

A block's place: whole numbers x, y and z. y runs from -64 to 191.

Turn

How something is turned in space (a quaternion), with yaw and pitch read from it in degrees.

PlayerId

A player's lasting ID: the same each time they join, from their store account through Epic. Text, to be kept as it is.

CreatureId

A Voxelmon's lasting ID, a number.

Colour

A colour: Colour.rgb(r, g, b) from 0 to 255, or one of the game's own, such as Colour.GOLD.

Duration

A length of time, in seconds.

Time

A moment, as seconds since 1970 (UTC).

Value

Saved or setting data: text, a whole number, a float, true/false, a list of values or a table of named values.

Weather

The weather: kind (CLEAR, RAIN, SNOW or STORM) and strength from 0 to 1.

WorldOptions

The world's settings, as in server.toml: difficulty (NORMAL, HARD, HARDCORE), combat (TURN_BASED, ACTION), keep_inventory, creative. Creative and the combat style may be changed while running: set_creative(on), set_combat(style).

CommandHandler

What a console command runs: it is given the words typed after the command's name and returns the lines to print.

Callback

Code to run later: a closure in Rust, a lambda in Java.

Service

Something one plugin offers others by name (economy, permissions): an object of methods both agree on.

HttpRequest

An HTTP request: method, url, headers and body. The host must be in the manifest's internet_hosts.

HttpResponse

An HTTP answer: status, headers and body.

Lists and maybe

List[T] is a list of T. T? is a T or nothing.
