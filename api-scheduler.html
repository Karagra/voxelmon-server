Scheduler

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

From server.scheduler().

Running code later, or again and again.

Description

Times are in ticks (60 a second) or seconds. Every task runs on the server's tick. A Java plugin may also run work off the tick (off_tick), which must not touch the world; its result comes back with then on the tick.

Methods

ReturnsMethodDescription
Tasknext_tick(run: Callback)Runs once, on the next tick.
Taskafter(ticks: int, run: Callback)Runs once after a number of ticks.
Taskafter_seconds(seconds: float, run: Callback)Runs once after some seconds.
Taskevery(ticks: int, run: Callback)Runs again and again, a number of ticks apart.
Taskevery_seconds(seconds: float, run: Callback)Runs again and again, some seconds apart.
Taskoff_tick(work: Callback)Java only: runs work on another thread, never touching the world.
nothingcancel_all()Cancels every task this plugin made.
