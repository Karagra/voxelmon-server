Content packs

New things for a server's world, made of data alone: no code. Players' headsets download a server's packs when they join, after asking.

Planned. Nothing here can be used yet; the format may change until the first content pack release.

What a pack is

A pack is a folder (or a .zip of one) in the server's packs/ folder, approved by the owner as plugins are. It holds a pack.toml and the files it names:

my-pack/
  pack.toml
  items/ruby.toml
  blocks/ruby_ore.toml
  models/ruby.bbmodel        # made in Blockbench
  textures/ruby_ore.png      # 16 x 16
  recipes/ruby_sword.toml
  loot/ruby_mine.toml
  spawns/desert.toml
# pack.toml
id = "rubies"
name = "Rubies"
version = "1.0.0"
api = "1"
authors = ["Karagra"]
description = "Ruby ore, ruby tools and a ruby sword."

What a pack can add

KindFolderWhat it sets
Itemsitems/Name, model (a Blockbench .bbmodel), stack limit, kind (material, tool, weapon, armour, food), tier, stats, worth in coins, how it is held
Blocksblocks/Name, textures for each face (16 by 16 pixels, in the game's style), hardness, the tool that breaks it best, what it drops, light it gives, its sounds (from the game's own)
Furniture and objectsobjects/A model placed in the world: its footprint, whether it can be sat on, opened or stored in
Recipesrecipes/What is made, from what, and at which station: workbench pattern, anvil pattern, fletching bench, forge smelting, cauldron brew, campfire rim or cooking pot
Lootloot/Additions to the game's loot: chests of towns, dungeons by tier, wrecks, cave finds, fishing, a beaten species
Spawnsspawns/Where and how often Voxelmon appear: species, habitats or biomes, levels, time of day
Shopsshops/Items townspeople's shops offer, and their prices

Not yet: new Voxelmon species, new sounds and music, and changing the game's own items. Each will be listed here when it comes.

Names and numbers

Things are named in a pack by the pack's id and their own, such as rubies:ruby. The world gives each pack item and block a number of its own the first time it sees it and keeps it with the world, so packs can be added to a world later and never collide.

Limits

LimitWhy
A server's packs together: at most 64 MBHeadsets download them on joining.
A model: at most 4,096 boxes and a 256 by 256 pixel textureDrawn on a headset at 72 to 120 frames a second.
Block textures: 16 by 16 pixelsThe game's own size; they join the game's texture array.
PNG and Blockbench files onlyThe headset checks every file before using it, and refuses anything else.

On players' headsets

When a player joins a server with packs, their game shows the packs' names and sizes and asks before downloading. Packs are kept on the headset by their exact contents, so joining again, or another server with the same pack, downloads nothing. A headset never runs anything from a pack: it reads data, checked against these limits.
