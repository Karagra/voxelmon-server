PlacedObject

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

From world.objects_near(...), world.object_at(...) and events.

Something placed that is more than a block: furniture, stations, chests, beds, doors, crops.

Properties

TypeNameDescription
ItemTypeitemWhat it is.
BlockPosatIts first block.
floatfacingWhich way it faces.
List[BlockPos]fillsEvery block it fills.
Station?stationWhat kind of station it is, if one.
boolopenWhether a door or lid stands open.
int?crop_percentHow grown a crop is, 0 to 100.

Methods

ReturnsMethodDescription
Container?container()Its contents, for a chest, barrel or shelf.
nothingset_open(open: bool) world_editOpens or shuts a door or lid.
nothingremove(drop: bool) world_editTakes it down, dropping it as an item or not.

Station

Workbench, anvil, fletching bench, forge, brewing cauldron, campfire, or cooking pot.

Events

Related events: ObjectPlacing, ObjectRemoved, ContainerOpening, DoorUsed.
