Creature

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

From world.creatures_near(...), a team, a cube or events.

One Voxelmon: wild, a player's companion, or stored in a player's team.

Description

A creature has a lasting id. A wild one exists only while it is in the world; a player's is kept with them. Its species, level, size and moves are its own (two of a species differ). Spawning, changing and removing creatures needs creatures.
