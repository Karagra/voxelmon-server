Storage

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

From server.storage().

Data a plugin keeps between runs: its own, and some for each player.

Description

Values are text, numbers, true/false, lists and tables, saved with the world. A plugin sees only its own. For files of its own, a plugin with the files need reads and writes in its folder, plugins/<id>/.
