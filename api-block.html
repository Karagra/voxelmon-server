Block

Available. Every call here works on servers today.

Plain data, copied: fields in both directions.

One block in the world: what it is and where.

FieldDescription
at: BlockPosBlockPos at()Where it is.
r#type: BlockTypeBlockType type()What it is.
sky_light: i64long skyLight()Daylight reaching it, 0 to 15.
block_light: i64long blockLight()Light from torches, lava and lamps, 0 to 15.

BlockType

Handle: stands for something in the game; its calls fail with Gone once it is gone.

A kind of block.

MethodDescription
fn id(&self) -> Result<i64>long id()Its lasting number.
fn name(&self) -> Result<String>String name()Its name.
fn solid(&self) -> Result<bool>boolean solid()Whether bodies stand on it and cannot pass.
fn liquid(&self) -> Result<bool>boolean liquid()Water or lava.
fn light(&self) -> Result<i64>long light()Light it gives, 0 to 15.
fn hardness(&self) -> Result<f64>double hardness()Seconds to break it by hand.
fn item(&self) -> Result<Option<ItemType>>Optional<ItemType> item()The item it is as carried.
fn named(name: &str) -> Result<Option<BlockType>>static Optional<BlockType> named(String name)A block by its name (any case).
fn by_id(id: i64) -> Result<Option<BlockType>>static Optional<BlockType> byId(long id)A block by its number.
fn air() -> Result<BlockType>static BlockType air()Air: nothing.
