Networking

Players join with a six-character join code. On your own network or across the internet, the code is all they need.

How players find the server

When a player enters the code, their game looks for it two ways at once:

  • On the same network (the same Wi-Fi or LAN as the server), the game finds the server directly and connects to it straight.
  • Over the internet, the game asks Epic Online Services, where the server has registered its code. Epic connects the two directly where the routers allow it, and through Epic's relay where they do not. Nothing has to be forwarded on your router for this.

If both work, the game uses the same-network connection.

Accounts

Every player must be signed in to their store account (Meta Quest or PICO). When a player joins, the server asks Epic to confirm their account; a player Epic cannot vouch for is turned away with a message saying so. This needs the server to reach Epic, so it needs the internet even when every player is on your own network.

The server signs in to Epic with an anonymous identity of its own, made on its first run and kept in its epic/ folder. You need no Epic account.

Ports and firewalls

PortUsed forNeeded when
UDP 25565 (port)The game's own connectionsPlayers on the same network
UDP 25566Answering join codes on the networkPlayers on the same network
Outgoing HTTPS and UDPEpic Online ServicesAlways (accounts, internet play)

Internet play through Epic needs no incoming ports: the server reaches out to Epic, which is allowed by almost every firewall. Only same-network joins need the two incoming UDP ports open on the server's own firewall.

Opening them

Windows: allow voxelmon-server.exe when Windows asks on the first run, or add an inbound rule for UDP 25565 and 25566.

Linux with firewalld (Fedora, CachyOS and others):

sudo firewall-cmd --permanent --add-port=25565-25566/udp
sudo firewall-cmd --reload

Linux with ufw (Ubuntu and others):

sudo ufw allow 25565:25566/udp

If a player on your network cannot find the server but players elsewhere can, these ports are the first thing to check. Their game then falls back to Epic, which works too, just not as directly.

MessageMeaning

Bandwidth

Each player sends and receives only what is near them, and a player standing still costs very little. As a rough guide, allow 30 to 60 KB/s of upload for each active player; a home connection with 20 to 40 Mbit/s of upload holds about 40 to 60 busy players.
