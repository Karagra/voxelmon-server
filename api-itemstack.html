ItemStack

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

A value: made with ItemStack.of(item, count).

Some of one item: what it is and how many.

Description

An item's type is an ItemType, found by name (ItemType.named("Iron Ingot")) or by its id. Items added by content packs are found the same way. A capture cube holding a Voxelmon is an item too, carrying its creature.

Properties

TypeNameDescription
ItemTypeitemWhat it is.
intcountHow many, from 1 to its stack limit.
Creature?creatureThe Voxelmon in a capture cube, if it holds one.
intwearHow worn a starter tool is (0 new).

Methods

ReturnsMethodDescription
ItemStackof(item: ItemType, count: int)Makes a stack.
ItemStackwith_count(count: int)The same item, another count.

ItemType

A kind of item: every block, tool, food, material, piece of gear, cube and station.

TypeFieldDescription
intidIts lasting number.
StringnameIts name as players see it, such as IRON INGOT.
intstack_limitHow many fit in one slot.
ItemKindkindBlock, tool, weapon, armour, food, material, cube, station, furniture.
Tier?tierIts tier, for tools and gear: flint, wood, copper, iron, cobalt, abyssal, voxelium.
intvalueWhat it is worth in coins in shops.
BlockType?blockThe block it places, if any.
String?packThe content pack it comes from, if any.
