Getting started

Download, unzip and run. The server writes everything it needs on its first run.

Download

Each release on the releases page has a package for each kind of computer:

PackageFor
voxelmon-server-windows-x64.zipWindows 10 or 11, 64-bit
voxelmon-server-linux-x64.tar.gzLinux on Intel or AMD, 64-bit (any distribution from about 2020 on)
voxelmon-server-linux-arm64.tar.gzLinux on 64-bit ARM, such as a Raspberry Pi 5 or an ARM cloud server

Each package holds the server, Epic's library for internet play and a short README. Use the server version that matches the game version your players have.

First run

Windows

Unzip the package into a folder of its own and double-click voxelmon-server.exe, or from a terminal in that folder:

voxelmon-server.exe

Linux

tar xzf voxelmon-server-linux-x64.tar.gz
cd voxelmon-server-linux-x64
./voxelmon-server

On its first run the server writes server.toml (every setting, explained) and makes a new world in world/. It then prints its join code:

VoxelMon server: world seed 14705190437188718191, up to 8 players
Listening on UDP 192.168.1.20:25565. Type `help` for commands.
Join code: DSS4YV (players on this network; UDP 25566)
Opening the join code to the internet...
Players anywhere can join with the code.

Players enter that code on the Multiplayer page of the game's main menu. The code stays the same each time the server starts, as long as the computer keeps the same address on its network, so you can share it once. (Give the server a fixed address in your router if it moves.)

A different folder

To keep the world somewhere else, give the folder as the first argument. Everything the server writes goes there:

./voxelmon-server /srv/my-voxelmon-world

What is in the folder

FileWhat it is
server.tomlYour settings. See Settings.
world/The world, and a file for each player who has joined. Back this folder up.
blocked.txtPlayers who may never join, added with the block command.
code.secretWhat keeps the join code the same between runs. Delete it to get a new code.
epic/Epic's sign-in for this server, made on the first run.

Stopping and saving

Type stop, or press Ctrl-C: players are told, the world is saved and the server ends. It also saves every five minutes on its own (autosave_minutes). Closing the window on Windows saves too.

Keeping it running on Linux

A systemd service starts the server with the machine and restarts it if it stops. Make a user for it, put the package in /opt/voxelmon, then write /etc/systemd/system/voxelmon.service:

[Unit]
Description=VoxelMon dedicated server
After=network-online.target
Wants=network-online.target

[Service]
User=voxelmon
ExecStart=/opt/voxelmon/voxelmon-server /var/lib/voxelmon
Restart=on-failure
KillSignal=SIGTERM
TimeoutStopSec=30

[Install]
WantedBy=multi-user.target
sudo useradd --system --home /var/lib/voxelmon --create-home voxelmon
sudo systemctl enable --now voxelmon
journalctl -u voxelmon -f      # its output, including the join code

Run as a service the server has no console to type into; stop and start it with systemctl. Its world and settings are in /var/lib/voxelmon.

Updating

Stop the server, replace the program and Epic's library with the new version's, and start it again. Your server.toml, world/ and blocked.txt stay as they are. Players must update their game to the same version to join.

How much computer it needs

Measured with 255 test players spread over the map: about 300 MB of memory and just over half of one CPU core. For players doing everything at once (battles, building, crafting), plan on roughly:

PlayersComputerUpload speed
Up to 20Any recent PC or a small cloud server10 Mbit/s
20 to 50A recent PC or a 2-core cloud server25 Mbit/s
50 to 100A fast core; a dedicated or rented server50 Mbit/s

Upload speed is usually what runs out first on a home connection. Over 100 players is possible: test it with your own players first.
