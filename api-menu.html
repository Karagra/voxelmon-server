Description

A menu floats before the player in the game's own panel style, and they point and press as on any panel. The plugin only describes it; the player's game draws it, so no plugin code runs on the headset. Each press comes back as a MenuPressed event with the pressed element's id; the plugin decides what happens, and may change the menu while it is open (it updates in place).

A menu with an anchor stands at that place in the world for every player near it (a shop's board); without one, it floats before the player it was opened for.

Limits, so every menu stays light on a headset: 8 tabs, 64 elements a tab, 24 item tiles a tab.
