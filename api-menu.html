Menu

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

Made with Menu.new(title); shown with player.open_menu(menu).

A panel a plugin shows a player: tabs down its left side, and in each tab buttons, item tiles, toggles, sliders and text.

Description

A menu floats before the player in the game's own panel style, and they point and press as on any panel. The plugin only describes it; the player's game draws it, so no plugin code runs on the headset. Every press comes back to the plugin as a MenuPressed event, carrying the pressed element's id; the plugin decides what happens, and may change the menu while it is open (it updates in place).

A menu can also stand in the world at a place (anchor), as a shop's board does, for any player who points at it.

Example: a warp menu with a tab for each kind of place, each place a button, and a settings tab with a toggle.

Properties

TypeNameDescription
StringtitleIts title, across the top.
List[Tab]tabsIts tabs, down the left side; a menu of one tab shows no tab column.
Place?anchorA place in the world where it stands for everyone, or none to float before one player.

Methods

ReturnsMethodDescription
Menunew(title: String)An empty menu.
Tabtab(id: String, title: String, icon: ItemType?)Adds a tab, with an item drawn as its icon.
nothingselect_tab(id: String)Which tab shows first.
nothingupdate()Sends changes to every player who has it open.
nothingclose_for_all()Closes it for everyone.
List[Player]viewers()Who has it open.

Tab

One tab of a menu: rows of elements, laid out top to bottom, each row's elements side by side.

TypeFieldDescription
Tabtext(id, text)A line of text.
Tabheading(id, text)A heading.
Tabbutton(id, text)A button.
Tabitem(id, stack, tooltip)An item tile: its model, count and a card when pointed at.
Tabtoggle(id, text, on)An on/off switch.
Tabslider(id, text, min, max, value)A slider.
Tabcreature(id, creature)A Voxelmon's portrait with its name and level.
Tabrow()Starts a new row.
Tabgrid(columns)Lays the next elements out in a grid (a shop's items).
nothingset(id, value)Changes an element: a text, a toggle, a tile.
nothingenable(id, on)Greys an element out, or not.
nothingclear()Empties the tab.

Events

Related events: MenuPressed, MenuClosed.
