Plugin

What a plugin implements.

What a plugin is: the code the server calls as it starts, as the world becomes ready and as it stops.

MethodDescription
fn enable(server: &Server) -> Selfpublic void enable(Server server)Called once loaded. Listen for events, register commands and tasks.
fn world_ready(&mut self)public void worldReady()Called once the world has loaded and players may join.
fn disable(&mut self)public void disable()Called when the server stops or the plugin is reloaded: save what it keeps.

Description

In Rust a plugin is a type implementing Plugin, named with the voxelmon_plugin! macro; in Java a class extending VoxelmonPlugin, named in its plugin.toml. The server makes it with enable, where it listens for events and registers commands and tasks. See Writing a plugin for the manifest.
