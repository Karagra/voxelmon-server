Scheduler

Available. Every call here works on servers today.

Reached from the server: server.scheduler().

Running code later, or again and again.

MethodDescription
fn next_tick(&self, run: impl FnMut() + 'static) -> Result<Task>Task nextTick(Runnable run)Runs once, on the next tick.
fn after(&self, ticks: i64, run: impl FnMut() + 'static) -> Result<Task>Task after(long ticks, Runnable run)Runs once after a number of ticks.
fn after_seconds(&self, seconds: f64, run: impl FnMut() + 'static) -> Result<Task>Task afterSeconds(double seconds, Runnable run)Runs once after some seconds.
fn every(&self, ticks: i64, run: impl FnMut() + 'static) -> Result<Task>Task every(long ticks, Runnable run)Runs again and again, a number of ticks apart.
fn every_seconds(&self, seconds: f64, run: impl FnMut() + 'static) -> Result<Task>Task everySeconds(double seconds, Runnable run)Runs again and again, some seconds apart.
fn cancel_all(&self) -> Result<()>void cancelAll()Cancels every task this plugin made.

Description

Times are in ticks (60 a second) or seconds. Every task runs on the server's tick, after the world's step.

Task

Handle: stands for something in the game; its calls fail with Gone once it is gone.

A scheduled task.

MethodDescription
fn running(&self) -> Result<bool>boolean running()Whether it is still to run.
fn cancel(&self) -> Result<()>void cancel()Stops it running.
