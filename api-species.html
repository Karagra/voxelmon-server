Species

Available. Every call here works on servers today.

Handle: stands for something in the game; its calls fail with Gone once it is gone.

A kind of Voxelmon: its essences, its moves, where it lives and what it becomes. The game's own and the server's (content packs' species/*.toml) alike.

MethodDescription
fn id(&self) -> Result<i64>long id()Its lasting number (a content pack's species: its number while the server runs; keep it by name or key).
fn name(&self) -> Result<String>String name()Its name, such as LUNAPUP.
fn essence(&self) -> Result<Essence>Essence essence()Its first essence.
fn second_essence(&self) -> Result<Option<Essence>>Optional<Essence> secondEssence()Its second essence, if it has one.
fn rarity(&self) -> Result<Rarity>Rarity rarity()How often it appears in the wild.
fn temperament(&self) -> Result<Temperament>Temperament temperament()How it treats players.
fn habitats(&self) -> Result<Vec<Habitat>>List<Habitat> habitats()Where it lives.
fn locomotion(&self) -> Result<Locomotion>Locomotion locomotion()Walks, swims or both.
fn evolutions(&self) -> Result<Vec<Evolution>>List<Evolution> evolutions()What it becomes.
fn base_stats(&self) -> Result<Stats>Stats baseStats()Its stats before levels.
fn learns(&self) -> Result<Vec<LearnedMove>>List<LearnedMove> learns()The moves it learns, and at which levels.
fn named(name: &str) -> Result<Option<Species>>static Optional<Species> named(String name)A species by name (any case), or a content pack's by its key (pack:name).
fn by_id(id: i64) -> Result<Option<Species>>static Optional<Species> byId(long id)A species by number.
fn all() -> Result<Vec<Species>>static List<Species> all()Every species: the game's own, then the content packs'.

Move

Handle: stands for something in the game; its calls fail with Gone once it is gone.

A battle move: the game's own or a content pack's (moves/*.toml).

MethodDescription
fn id(&self) -> Result<i64>long id()Its lasting number (a content pack's move: its number while the server runs).
fn name(&self) -> Result<String>String name()Its name.
fn essence(&self) -> Result<Option<Essence>>Optional<Essence> essence()Its essence, or none for a plain move.
fn power(&self) -> Result<i64>long power()How hard it hits (0 for a move that does not).
fn accuracy(&self) -> Result<i64>long accuracy()Its chance to land, in percent.
fn named(name: &str) -> Result<Option<Move>>static Optional<Move> named(String name)A move by name (any case), or a content pack's by its key (pack:name).

Evolution

Plain data, copied: fields in both directions.

What a species becomes.

FieldDescription
into: SpeciesSpecies into()The species it becomes.
level: i64long level()The level it may evolve at.

LearnedMove

Plain data, copied: fields in both directions.

A move a species learns.

FieldDescription
r#move: MoveMove move()The move.
level: i64long level()The level it is learned at.
