Server

Being built. 27 of 33 calls here work on servers today; the rest are marked not yet and answer that they are not available. Names may still change until the first plugin release.

Reached from the server: server.server().

Description

Everything a plugin does starts here. The server ticks 60 times a second; plugin code runs on the tick, so a plugin never needs to lock anything to read the world.

What a plugin changes inside a stoppable event's listener takes effect as soon as the listener returns; everything else takes effect at once.
