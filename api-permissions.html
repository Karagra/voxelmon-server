Permissions

Planned. The plugin API is being built: nothing here can be used yet, and names may change until the first plugin release.

From server.permissions().

Who may do what: operators and permission names.

Description

A permission is a name such as warps.set. The server keeps operators in server.toml (operators = [...], by player ID): an operator has every permission. Anything finer, such as groups and ranks, comes from a permission manager plugin, which provides the permissions service; every plugin's checks then go through it.

Methods

ReturnsMethodDescription
boolhas(player: Player, permission: String)Whether a player has a permission.
nothingdeclare(permission: String, default: PermissionDefault, description: String)Names a permission this plugin checks, so owners and managers can list it.
boolis_operator(id: PlayerId)Whether a player is an operator.
nothingadd_operator(id: PlayerId)Makes a player an operator (written to server.toml).
nothingremove_operator(id: PlayerId)Takes a player off the operators.
List[String]declared()Every permission every plugin declared.

Values

ValueMeaning
PermissionDefault.EVERYONEEveryone has it unless a manager says no.
PermissionDefault.OPERATORSOnly operators, unless a manager gives it.
PermissionDefault.NOBODYNobody, unless a manager gives it.
