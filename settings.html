Settings

Everything is in server.toml in the server's folder. Restart the server after changing it.

The first run writes the file with every setting and an explanation of each. A line starting with # is a comment. Text goes in quotes; numbers and true/false do not. If a line has a mistake (an unknown setting or a value out of range), the server does not start and names the line, so a typo never quietly falls back to a default.

All settings

SettingDefaultWhat it does
port25565The UDP port players' games connect to, 1 to 65535. Join codes are always answered on UDP 25566.
max_players8Players at once, 1 to 255. See how much computer it needs.
title"VoxelMon Server"The name players see when they look up the join code.
description""A line shown under the title.
seedrandomThe seed for a new world, a whole number. Leave it out for a random world. An existing world keeps its own seed.
autosave_minutes5Minutes between automatic saves, 0 to 1440. 0 saves only on the save and stop commands.
internettrueOpens the join code to players on other networks through Epic Online Services. Must stay on: see below.
difficulty"normal""normal"; "hard" (creatures hit harder and starving can make you faint); or "hardcore" (hard, and one life: a player who faints stays down for good in this world).
combat"turn-based""turn-based" battles, or "action" for real-time combat.
keep_inventorytrueA player who faints keeps everything they carry.
creativefalseFree flight, no harm and unlimited blocks for every player.
The server lets in only players signed in to their store account, as confirmed by Epic Online Services. That check needs the internet, so internet must stay true even if all your players are on your own network: with it off, nobody can join.

An example

# A hardcore server for up to 30 friends.
port = 25565
max_players = 30
title = "Karagra's Hardcore World"
description = "One life. Make it count."
autosave_minutes = 5
internet = true
difficulty = "hardcore"
combat = "action"
keep_inventory = false
creative = false
